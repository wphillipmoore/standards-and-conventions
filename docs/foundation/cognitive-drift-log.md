## Purpose
Provide a minimal log template for recording concerning or hard failures.

## Scope
Use when a response or behavior violates the interaction contract.

## Template
```
Date:
Context:
Prompt:
Observed failure:
Category (A–F):
Severity (Soft / Hard):
Correction applied:
```

## Prompt shortcuts
Use a standalone prompt that invokes the log, such as:
- `Log cognitive drift`
